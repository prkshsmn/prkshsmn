## Hi, I'm Prakash

I'm a software engineer at Exelon, where I build the data pipelines and API integrations
behind HR systems used by about 40,000 employees, and lead my team's adoption of AI coding
tools. Outside work I run a self-hosted platform at home and treat it like production: every
job is measured, every alert has to earn its place, and every fix is checked by its effect.

### What I build

- **Data and integrations.** SQL-driven ETL and ELT pipelines, REST integrations through
  Apigee, and automation in Python, Java and C#.
- **A homelab run like a small platform.** Proxmox, Docker, Cloudflare Tunnel, secrets
  encrypted with SOPS and age, offsite backups that are verified by hash and restore-tested.
  The public write-up, with the incidents that taught me the most, is in
  [homelab-showcase](https://github.com/prkshsmn/homelab-showcase).
- **Measurement before opinion.** I built a small [usage store](https://github.com/prkshsmn/usage-store) (one SQLite file fed by cron
  collectors) so that "is this used?" has a number. It cut my own alert volume from about
  eleven pushes a day to one or two.
- **A personal finance and health tracker** with its own Postgres schema and bank sync, and a
  job-search pipeline that reads company career boards and filters by level.

### How I work

- Check the effect, not the exit code.
- Prefer the complete fix over the quick one, and say plainly what is left undone.
- One change that removes a class of problem beats five patches.
